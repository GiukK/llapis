===============================================================================
LLapis - third-party components
===============================================================================

This file inventories the third-party code that reaches a built, running LLapis.
It was derived from the tree that is actually distributed, not from a dependency
manifest:

  * the vendored C/C++ libraries were taken from the include sites in the source
    files that compile into the shipped targets;
  * the web-UI packages were taken from the import statements in the UI sources
    that produce the shipped UI bundle, with versions and licence strings read from
    resolved packages;
  * the build-only npm tooling (73 devDependencies: vite, eslint, prettier,
    typescript, the test runner, and so on) is NOT listed, because none of it is
    in the bundle. Listing it would pad this file with obligations nobody has.

Model weights are not covered here. LLapis does not distribute them - see the
last section.

6. Model weights - not distributed here
===============================================================================

No model weights are in this repository and none are downloaded by the build.
LLapis reads GGUF files the user obtains themselves.

The models README.md recommends are published by third parties under their own
terms:

  Gemma 4 26B-A4B-it            Apache-2.0, published by Google
                                https://huggingface.co/google/gemma-4-26b-a4b-it
  GGUF quantizations            Apache-2.0, published by Unsloth AI, derived
                                from the model above
                                https://huggingface.co/unsloth/gemma-4-26B-A4B-it-GGUF

Both repositories declare Apache-2.0 and neither is access-gated as of
2026-08-06. Verify the terms at the source before redistributing: the licence a
model is published under can change between revisions, which is why README.md
pins a repository revision rather than a moving branch.
